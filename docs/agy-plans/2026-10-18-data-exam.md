## Hợp đồng dữ liệu giao diện

ExamPractice nhận prop bank gồm lesson, title và questions.
Mỗi question có id, kind (quiz/essay), group (core/extension/regex), promptHtml,
options [{key:A/B/C/D, html, explanationHtml}], correctKey (quiz), answerHtml,
verificationHtml. HTML được Codex render sẵn bằng renderer VitePress, chứa
code highlight và MathJax tĩnh. Không cần runtime Markdown hoặc gọi dịch vụ.

## Hợp đồng review

Mỗi review JSON gồm lesson và items, đúng toàn bộ id của bài. Mỗi item có id,
correctKey (null với essay), optionExplanations {A,B,C,D} (rỗng với essay),
explanationMarkdown (giải thích bổ sung nếu cần, không thay/xóa đáp án gốc),
verification {method, evidence, limitations}. Kiểm chứng thực, không sao chép
câu nguồn nói đã kiểm. Chỉ ra đáp án mơ hồ/sai và sửa có bằng chứng. Các câu
chính sách được đánh giá theo giả thiết tài liệu, không tự coi là luật hiện hành.

Chạy Python tính lại ví dụ/code, giữ trường hợp lỗi dự kiến. Không chạy shell
trong đề vào máy thật, không tải dữ liệu ngoài đề hoặc dùng API key. Mô phỏng
tệp/API bằng dữ liệu được đề cung cấp. Thư viện đã có tại
C:/Users/Ai/AppData/Local/Temp/studyhub-data-python (PYTHONPATH), phiên thực tế
Python 3.14.7, NumPy 2.5.2, pandas 3.0.5. Khác phiên bản nguồn phải ghi rõ.
