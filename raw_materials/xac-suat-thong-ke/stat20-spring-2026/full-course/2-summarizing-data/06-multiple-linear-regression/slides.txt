Concept Questions

Today’s questions are centered around a few different linear models made using the data in the penguins data frame.

m1 <- lm(flipper_length_mm ~ bill_length_mm, data = penguins)

m2 <- lm(flipper_length_mm ~ bill_length_mm + species, 
         data = penguins)

m3 <- lm(flipper_length_mm ~ bill_length_mm + bill_depth_mm, 
         data = penguins)

m4 <- lm(flipper_length_mm ~ bill_length_mm + 
  bill_depth_mm + species, 
         data = penguins)

         data = penguins)

m4 <- lm(flipper_length_mm ~ bill_length_mm + 
  bill_depth_mm + species, 
         data = penguins)

How many more coefficients does the model m4 have than m1?

m4 has one more numerical variable than m1, and one more categorical variable as well. This adds 1 more coefficient and 2 more coefficients (there are three penguin species, so 3-1), respectively. The correct answer should be three more coefficients.
