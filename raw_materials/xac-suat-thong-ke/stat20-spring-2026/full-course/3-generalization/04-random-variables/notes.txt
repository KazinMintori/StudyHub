Random variables

In each of the above scenarios, we had an outcome space 
[MATH] \(\Omega\), and then defined a function that assigned a real number to each possible outcome in 
[MATH] \(\Omega\). In our simulation above, if 
[MATH] \(\Omega\) is the set of outcomes 
[MATH] \(\{\text{``Heads'', ``Tails''}\}\), we assigned the outcome 
[MATH] \(\text{``Heads''}\) to the real number 
[MATH] \(1\), and the outcome 
[MATH] \(\text{``Tails''}\) to the real number 
[MATH] \(0\). By sampling over and over again from (0,1), we got a sequence of 
[MATH] \(0\)’s and 
[MATH] \(1\)’s that was randomly generated by our sampling. Once we had numbers (instead of sequences of heads and tails), we were able to do operations using these numbers, such as compute the proportion of times we sampled 
[MATH] \(1\), or represent the probabilities as a histogram. Moving from non-numeric outcomes in an outcome space 
[MATH] \(\Omega\) to numbers on the real line is enormously useful.

In mathematical notation:

[MATH] \[ X : \Omega \rightarrow \mathbb{R}\]

[MATH] \(X\) is called a random variable: variable, because it takes different values on the real line, and random, because it inherits the randomness from the generating process (in this case, the process is tossing a coin).

Random variable

A random variable is a function that associates real numbers with outcomes from a random experiment where 
[MATH] \(\Omega\) is the associated outcome space.

The values on the real line that are determined by 
[MATH] \(X\) have probabilities coming from the probability distribution on 
[MATH] \(\Omega\). The range of the random variable 
[MATH] \(X\) is the set of all the possible values that 
[MATH] \(X\) can take. We usually denote random variables by 
[MATH] \(X, Y, \ldots\) or capital letters towards the end of the alphabet. We write statements about the values 
[MATH] \(X\) takes, such as 
[MATH] \(X = 1\) or 
[MATH] \(X = 0\). Note that 
[MATH] \(X = 1\) is an event in 
[MATH] \(\Omega\) consisting of all the outcomes that are mapped to the number 
[MATH] \(1\) on the real line. The probability of such events is written as 
[MATH] \(P(X = x)\), where 
[MATH] \(x\) is a real number.

Note that we are just formalizing the association of outcomes in 
[MATH] \(\Omega\) with numbers - an association we have seen before, while defining probability distributions. Earlier we defined probability distributions as how the total probability of 
[MATH] \(1\) or 
[MATH] \(100\)% was distributed among all possible outcomes of the random experiment. Now we can extend this definition to the associated real numbers as defined by 
[MATH] \(X\).

Probability distribution of a random variable 
[MATH] \(X\)

The set of possible values of 
[MATH] \(X\), along with the associated probabilities, is called the probability distribution for the random variable 
[MATH] \(X\).

Discrete and continuous random variables

Discrete random variables are restricted to take particular values in an interval, they cannot take just any value, as opposed to continuous random variables which can take any value in some specified interval.

The probability mass function or pmf of a discrete random variable

Probability mass function (pmf) of a discrete random variable 
[MATH] \(X\)

The pmf of a discrete random variable 
[MATH] \(X\) is defined to be the function 
[MATH] \(f(x) = P(X = x)\).

We can write down the definition of the function 
[MATH] \(f(x)\) and it gives the same information as in the table:

[MATH] \[
f(x) = \begin{cases}
          \frac{1}{8}, \; x = 0, 3 \\
          \frac{3}{8}, \; x = 1, 2
  \end{cases}
\]

We see here that 
[MATH] \(f(x) > 0\) for only 
[MATH] \(4\) real numbers, and is 
[MATH] \(0\) otherwise. We can think of the total probability mass as 
[MATH] \(1\), and 
[MATH] \(f(x)\) describes how this mass of 
[MATH] \(1\) is distributed among the real numbers. It is often easier and more compact to define the probability distribution of 
[MATH] \(X\) using 
[MATH] \(f\) rather than the table.

The Binomial Distribution

Recall that the binomial distribution describes the probabilities of the total number of successes in 
[MATH] \(n\) independent Bernoulli trials. We let 
[MATH] \(X\) be this total number of successes (think tossing a coin 
[MATH] \(n\) times, and counting the number of heads). Then we say that 
[MATH] \(X\) has the binomial distribution with parameters 
[MATH] \(n\) and 
[MATH] \(p\), and write 
[MATH] \(X \sim Bin(n,p)\), where 
[MATH] \(X\) takes the values in 
[MATH] \(\{0, 1, 2, \ldots, n\}\), and 
[MATH] \[P(X = k ) = \binom{n}{k} p^k (1-p)^{n-k}. \] Recall that the binomial coefficient 1 
[MATH] \(\displaystyle \binom{n}{k} = \frac{n!}{k!(n-k)!}.\)

The Hypergeometric Distribution

In the example above, we sampled 
[MATH] \(10\) California residents with replacement from a database of voters. Usually we always sample without replacement, so in a situation such as in the example, where we are define a random variable 
[MATH] \(X\) to be the number of successes in a simple random sample of 
[MATH] \(n\) draws from a population of size 
[MATH] \(N\), then 
[MATH] \(X\) will have the hypergeometric distribution with parameters 
[MATH] \(\left(N, G, n\right)\) where 
[MATH] \(G\) is the total number of successes in our population. We write this as 
[MATH] \(X \sim HG(N, G, n)\). If we let 
[MATH] \(X\) be the number of successes in 
[MATH] \(n\) draws, then we have that 
[MATH] \[ P(X = k) = \frac{\binom{G}{k} \times \binom{N-G}{n-k}}{\binom{N}{n}} \] where 
[MATH] \(N\) is the size of the population, 
[MATH] \(G\) is the total number of successes in the population, and 
[MATH] \(n\) is the sample size (so 
[MATH] \(k\) can take the values 
[MATH] \(0, 1, \ldots, n\) or 
[MATH] \(0, 1, \ldots, G\), if the number of successes in the population is smaller than the sample size.)

Example: Gender discrimination at a large supermarket?

A large supermarket chain in Florida (with 1,000 employees) occasionally selects employees to receive management training. A group of women there claimed that female employees were passed over for this training in favor of their male colleagues. The company denied this claim. (A similar complaint of gender bias was made about promotions and pay for the 1.6 million women who work or who have worked for Wal-Mart. The Supreme Court heard the case in 2011 and ruled in favor of Wal-Mart, in that it rejected the effort to sue Wal-Mart.)3 If we set this up as a probability problem, we might ask the question of how many women have been selected for executive training in the last 10 years. In order to do the math, we can simplify the problem. Suppose no women had ever been selected in 10 years of annually selecting one employee for training. Further, suppose that the number of men and women were equal, and suppose the company claims that it draws employees at random for the training, from the 1,000 eligible employees. If 
[MATH] \(X\) is the number of women that have been picked for training in the past 10 years, what is 
[MATH] \(P(X = 0)\)?

Note that we are picking a sample of size 10 without replacment and counting the number of women in our sample and therefore, a “success” will be selecting a woman. Modeling 
[MATH] \(X\) as a hypergeometric random variable, we have that 
[MATH] \(N = 1,000\), there are 1,000 employees, and since half are women, we have 
[MATH] \(G = N-G = 500\). We want to compute the probability that out of the 
[MATH] \(10\) employees that were selected at random from the 
[MATH] \(1,000\) employees, none are women. This gives us, using the formula above:

[MATH] \[P(X = 0) = \frac{\binom{500}{0} \times \binom{500}{10}}{\binom{1000}{10}} \approx 0.0009\] We will see later how to compute this probability in R.

The Poisson Distribution

There are three very important distributions that we see over and over again in many situations. One of them is the binomial distribution, which we have discussed above. The reason this distribution is so ubiquitous is that we use it for classifying things into binary outcomes and counting the number of “successes”. The second important discrete distribution is used to model many different things - from the number of people arriving at an ATM in a given period of time, to the frequency with which officers in the Prussian army were accidentally kicked to death by their horses4. This distribution is called the Poisson distribution after a French mathematician, Siméon-Denis Poisson, who developed the theory in the nineteenth century.Interestingly, he was not the first French mathematician to develop this theory. That honor belonged to the seventeenth century mathematician who was a contemporary (and friend) of Isaac Newton, Abraham de Moivre.5 (The third important distribution is called the Normal distribution, also first discovered by de Moivre, which we will introduce later in the course.)

The Poisson distribution appears in situations when we have a very large number of trials in which we are checking the occurrence or not of a particular event which has a very low probability. That is, we have a very large number 
[MATH] \(n\) of Bernoulli trials, which have a very small 
[MATH] \(p\) or probability of success, such that the product 
[MATH] \(np\) is not too small or large. We call the number of successes 
[MATH] \(X\), and it counts the occurrence of events whose counts tend to be small. Note that 
[MATH] \(X \sim Bin(n, p)\), and 
[MATH] \[P(X = 0) = \binom{n}{0}\times p^0\times (1-p)^n = (1-p)^n.\] For large 
[MATH] \(n\), it turns out that 
[MATH] \((1-p)^n \approx e^{-\lambda}\), where 
[MATH] \(\lambda = np\). We won’t derive the distribution here, but we will use the Poisson distribution for random variables that count the number of occurrences of events in a given period of time in when the events result from a very large number of independent trials. The independence of the trials means that the probability of success does not change over time.

Poisson distribution

We say that such a random variable 
[MATH] \(X\) has the Poisson distribution with parameter 
[MATH] \(\lambda\), and write it as 
[MATH] \(X \sim Poisson(\lambda)\), if 
[MATH] \[ P(X = k) = e^{-\lambda} \frac{\lambda^k}{k!},\] where 
[MATH] \(k = 0, 1, 2, \ldots\). That is, the possible values of 
[MATH] \(X\) are non-negative integers, and since 
[MATH] \(k!\) grows much faster than 
[MATH] \(\lambda^k\), the probability that 
[MATH] \(X\) takes large values is very small. The parameter 
[MATH] \(\lambda\) is called the rate of the distribution, and represents how many “successes” we expect in the given time unit.

Binomial vs Hypergeometric distributions

Both the binomial and the hypergeometric distributions deal with counting the number of successes in a fixed number of trials with binary outcomes. The difference is that for a binomial random variable, the probability of a success stays the same for each trial, and for a hypergeometric random variable, the probability changes with each trial. If we use a box of tickets to describe these random variables, both distributions can be modeled by sampling from boxes with each ticket marked with 
[MATH] \(0\) or 
[MATH] \(1\), but for the binomial distribution, we sample 
[MATH] \(n\) times with replacement and count the number of successes by summing the draws; and for the hypergeometric distribution, we sample 
[MATH] \(n\) times without replacement, and count the number of successes by summing the draws.

Note that when the sample size is small relative to the population size, there is not much difference between the probabilities if we use a binomial distribution vs using a hypergeometric distribution. Let’s look at the gender discrimination example again, and pretend that we are sampling with replacement. Now we can use the binomial distribution to compute the chance of never picking a woman. Let 
[MATH] \(X\) be defined as before, as the number of women selected in 
[MATH] \(10\) trials.

[MATH] \[
P(X = 0) = \binom{10}{0}\times\left(\frac{1}{2}\right)^0\times\left(\frac{1}{2}\right)^{10} = 0.0009765625 \approx 0.00098
\] 

Recall that the probability using the hypergeometric distribution was 0.0009331878. You can see that the values are very close to each other. This is an illustration of the fact that we can use a binomial random variable to approximate a hypergeometric random variable if the sample size 
[MATH] \(n\) is very small compared to the population size 
[MATH] \(N\).

Now we will define another important quantity related to random variables. This quantity called the cumulative distribution function is another way to describe the probability distribution of the random variable.

The cumulative distribution function 
[MATH] \(F(x)\)

Cumulative distribution function (cdf) 
[MATH] \(F(x)\)

The cumulative distribution function of a random variable 
[MATH] \(X\) is defined for every real number, and gives, for each 
[MATH] \(x\), the amount of probability or mass that has been accumulated up to (and including) the point 
[MATH] \(x\), that is, 
[MATH] \(F(x) = P(X \le x)\).

We usually abbreviate this function to cdf. It is a very important function since it also describes the probability distribution of 
[MATH] \(X\). In order to compute 
[MATH] \(F(x)\) for any real number 
[MATH] \(x\), we just add up all the probability so far: 
[MATH] \[
F(x) = \sum_{y \le x} f(y)
\]

For example, if 
[MATH] \(X\) is the number of heads in 
[MATH] \(3\) tosses of a fair coin, recall that:

[MATH] \[ f(x) = \begin{cases}
  \displaystyle \frac{1}{8}, \; x = 0, 3 \\
  \displaystyle \frac{3}{8}, \; x = 1, 2
  \end{cases} \]

In this case, 
[MATH] \(F(x) = P(X\le x) = 0\) for all 
[MATH] \(x < 0\) since the first positive probability is at 
[MATH] \(0\). Then, 
[MATH] \(F(0) = P(X \le 0) = 1/8\) after which it stays at 
[MATH] \(1/8\) until 
[MATH] \(x = 1\). Look at the graph below:

Notice that 
[MATH] \(F(x)\) is a step function, and right continuous. The jumps are at exactly the values for which 
[MATH] \(f(x) > 0\). We can get 
[MATH] \(F(x)\) from 
[MATH] \(f(x)\) by adding the values of 
[MATH] \(f\) up to and including 
[MATH] \(x\), and we can get 
[MATH] \(f(x)\) from 
[MATH] \(F(x)\) by looking at the size of the jumps.

Summary

In these notes, we defined random variables, and described discrete and continuous random variables.

For any random variable, there is an associated probability distribution, and this is described by the probability mass function or pmf 
[MATH] \(f(x)\).

We also defined a function that, for a random variable 
[MATH] \(X\), and any real number 
[MATH] \(x\), describes all the probability that is to the left of 
[MATH] \(x\). This function is called the cumulative distribution function (cdf) of 
[MATH] \(X\) and is denoted 
[MATH] \(F(x)\).

We looked at some special distributions (discrete uniform, Bernoulli, binomial, hypergeometric, and Poisson)
